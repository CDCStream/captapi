# Endpoint Competitive Gap Plan

Captapi vs ScrapeCreators. **Additive fields only** — never rename/remove keys customers already parse.

## Philosophy

- Keep envelope + camelCase + stable normalized shape
- Do not dump raw GraphQL / aweme by default
- Prefer exact counts when available; flag approximate otherwise
- Always expose stable platform IDs + real timestamps when raw has them

## #6 Transcript (YouTube + TikTok)

**Constraint:** many customers parse transcript endpoints — **additive only**. Do not rename transcript, transcriptSegments, wordCount, segments, language, or segment field names/types.

Captapi already wins vs SC on duration limit, float seconds, ISO language, Whisper fallback (TikTok). Gap was provenance in the **body**.

| Field | Priority | Status |
|---|---|---|
| source in body (captions / whisper / fallback) | P0 | Shipped additive (YT + TT) |
| isAutoGenerated | P1 | Shipped additive (YouTube captions path) |
| isTranslated | P1 | Shipped additive (YouTube) |
| availableLanguages[] | P1 | Shipped additive (YouTube) |
| Whisper confidence | P2 | Deferred (not exposed by current STT path) |
| Rename/reshape segment keys | — | **Never** |

Public source mapping (customers should rely on these strings):

- YouTube InnerTube captions → captions
- YouTube secondary actor path → fallback
- TikTok WebVTT captions → captions
- TikTok Whisper → whisper
